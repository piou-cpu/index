Scraped Flickr using the platform's image API for media tagged with the single keyword "furniture"; collecting not just the photographs but the rich metadata attached to them: usernames, timestamps, camera models, geolocation strings, and descriptions written in a dozen languages.

This project is an experiment in automated research, curation, and print-based layout. Everything from the layout engine to the covers was generated dynamically using JavaScript and Bindery.js, a browser-based book layout engine, utilizing little to no HTML. By letting the tool paginate and compose the material automatically, what began as a simple exercise in understanding a new program became a way to curate in tandem with the code itself. The result is a publication that exists somewhere between an intentional archive, a cultural catalog, and an attractive accident.

An experiment in research and curation; exploring the vast array of Flickr images through the guidelines of a single keyword, "furniture". The images range from clear shots of chairs, sofas, tables to artistic interpretations of the word itself.

At times, the odd image will sneak through. A motorcycle classified and tagged as a storage bench, a screenshot from what I can only suppose is a video game. From witty titles, like "Chairity", referring to a series of stacked chairs... to an image of an empty chair from 2015 titled "On Balkans, you can weight yourself on the street. Most often, this is the way to earn some extra money for people who retired and still want to stay useful".
